# Lotless

Tap a dealer-lot vehicle. See the factory-direct alternative — and an honest why / why-not.

No dealer network. No leads. No “certified” rooftops. Links go to the manufacturer, or nowhere.

## Local

Open `index.html` or:

```
npx serve .
```

## Deploy (Netlify)

1. New site → Import from GitHub → `WEPVentures/lotless`
2. Publish directory: `.`  (leave build command empty, or use the `netlify.toml` echo)
3. Deploy

## What this is not

A buyer’s agent. A lead funnel. An EV pamphlet. If the job is an 8-seat Tahoe and a boat, Lotless will tell you none of the DTC catalog replaces it.
